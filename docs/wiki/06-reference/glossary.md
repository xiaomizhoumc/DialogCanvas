# 06.6 术语表与资料权威顺序

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 无额外要求。

| 词语 | 在本项目中的含义 |
| --- | --- |
| MenuDefinition | 唯一菜单持久化业务模型，JSON/YAML 共用 |
| Dialog | 原生游戏对话框，不是网页模态窗 |
| ID/key | 菜单 ID、按钮 ID、输入 key、业务键各有独立作用域 |
| TextSpec | 字符串简写或 format/value 文本定义 |
| Sprite | 原生纹理图集中的按钮图标，非完整可旋转 3D 物品 |
| revision | API 并发校验的不透明字符串，不手算、不放菜单文件 |
| 同步基线 | JSON/YAML 摘要与导出意图；不是菜单历史副本 |
| 草稿 | 当前浏览器页面内存中的编辑文档，未必已经保存 |
| 临时预览 | 未提交字段或颜色窗口对预览的叠加层 |
| 应用 | 把窗口临时值提交到草稿，不是服务器保存 |
| FAIL / ERROR | 正常条件不满足 / 条件无法可靠求值 |
| 提交后副作用 | 已提交状态后发送消息/声音/命令/界面，无法通用撤回 |
| 补偿 | 根据已完成变更收据逆序尝试恢复，不是跨插件原子回滚 |
| pending / effectsPending | 未完成交易 / 状态已完成而副作用最终结果尚未确认 |
| dry-run | 只检查并解释候选，不清理 |
| archive | 校验和备份后移除合格失效条目，不删除所有玩家数据 |
| productionConnected | 生产链路已连接，不等于 Vault 服务提供者一定存在 |

## 权威顺序

代码/当前能力快照是实现事实；本 Wiki 是当前使用入口。REST 精确契约以 [WEB_API.md](../../../WEB_API.md) 最新增补及实现为准；菜单语义以生产校验器/渲染器和本 Wiki 字段表为准，meta 的结构 Schema 不包含所有语义限制。

根专题文档提供技术深度及历史验证记录，按最新日期增补读取；早期“计划/尚未接入/源码按钮”等文字不代表现在存在。PROJECT_CONTEXT 是开发时间线，不是新手教程；阶段测试数字保留原时间，不把它们相加冒充当前覆盖率。若资料冲突，以最新代码核对并报告差异，不自行手改生产数据试错。
