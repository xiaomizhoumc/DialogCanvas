# 03.1 YAML 基础与常见语法错误

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 会用 UTF-8 文本编辑器。

## 基础规则

| 概念 | 写法与解释 | 常见错误 |
| --- | --- | --- |
| 缩进 | 用空格；教学文件每层两空格 | 不用 Tab，不把同级字段错缩进到上一个对象 |
| 映射 | `id: wiki_first`，冒号后有空格 | `id:wiki_first` 可能变成普通字符串 |
| 列表 | 每个元素用 `- `，如 `body` 下的文本块 | 缩进错会把两个按钮合成一个对象 |
| 注释 | 引号外 `#` 后为注释 | `value: #55FF55` 实际是空值和注释 |
| 引号 | `'&6标题'`、`'#55FF55'`、`'%player_name%'` | `&` 可被当作锚点，`%` 可触发语法错误 |
| 单引号 | 字面字符；内部单引号写两个，如 `'玩家''的菜单'` | 单引号中的 `\n` 不会自动变换行 |
| 双引号 | `"第一行\n第二行"` 支持转义 | 反斜杠需考虑 YAML 转义，不能随意复制 Windows 路径 |
| 多行 | `|` 后缩进内容保留换行，`>` 折叠换行；`|-` 去末尾换行 | 缩进不能与外层字段齐平 |
| 布尔 | `true`/`false`，小写，不加引号 | 不用“是/否”或字符串 `'true'` 代替布尔字段 |
| 数字 | `1`、`16.5`；数值字段不能写 `'1'` | 动作 amount 是表达式字符串，反而应写 `'16'` |
| 空值 | `null` 或 `key:` 都是空值；省略代表没有显式配置 | 必填字段填 null 仍不合法，空列表 `[]` 不是 null |
| 大小写 | 字段 camelCase；类型 `multi_action`；周期 `DAILY` | 不把 `afterAction` 改成 `after_action`，不把 `DAILY` 写 daily |

含 `: `、开头 `#`/`&`/`%`、括号表达式、MiniMessage 标签时建议总用引号；例如 `text: '价格: 16'`。引号不会改变文字解析格式：`'&a欢迎'` 仍是 legacy 简写；要原样显示 &，使用 TextSpec plain。

`value: 'true'` 在字符串条件里是字符串；`initial: true` 在 bool 输入里是布尔，二者按字段类型选择。菜单版本 `schemaVersion: 1` 必须是整数；不能写 `'1'`。

## 完整而安全的教学方式

从完整文件复制，先只改中文标题/说明，保留 key/type。重复字段会被拒绝，不接受不安全对象标签或集合别名。只接受 JSON 兼容的字符串、数字、布尔、null、列表和字符串键对象；日期时间等应加引号，避免 YAML 隐式日期对象。

根文档必须是菜单对象，不是列表，不要加 API 的 menu 包装。所有完整教程代码块与对应示例文件自动比对；字段行只是说明，不是独立可运行菜单。
