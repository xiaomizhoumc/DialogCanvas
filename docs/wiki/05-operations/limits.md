# 05.5 已知限制与人工验收

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 知道自动测试、隔离服务端和客户端不是同一种证据。

## 已知限制

只支持 Paper 固定目标、本机 HTTP、单管理员；无数据库/RBAC/公网网站。渲染三类菜单、两类正文、四类输入；其他 POJO 保留字段不等于当前实现支持。无全服限购、模板、历史、diff、WebSocket 或游戏预览 API。

网页预览近似，复杂 Component/未支持 MiniMessage 原文保护不可视化强改；源码模式已移除。按钮 Sprite 无原生附魔光效，图集不涵盖全部材质。第三方私有物品没有通用解析器，任意模组物品不保证存在。临时 OP 只保证同步调用，其他插件权限结果由其实现决定。

有限 double 金额不是任意精度记账；跨 Vault/背包/多文件不具数据库原子性。无法确定的交易阻止重试，需要核查。外部编辑器与文件替换间不能承诺跨进程 CAS 或断电零丢失。YAML 注释/排版不往返。内存草稿关闭/刷新不保证恢复。

## 验收证据怎么读

最新阶段 10.5 完整构建：616 项 Java 中 612 通过、4 项既有 MockBukkit 跳过；前端 176 通过。四个版本各 15 项隔离 Paper 和 5 项真实 REST 浏览器流程通过；原生 Dialog 对象构造不是客户端显示。详见 [最终验收](../../../STAGE10_ACCEPTANCE.md)，历史报告不代替当前证据。

历史隔离 Paper 的服务发现、真实 REST/重启/端口保护见阶段 7/8/10.1/10.2。MockBukkit 未实现的原生 Dialog/默认物品属性测试不能算通过。历史提到“后来人工通过”仅适用于当时版本，不代替当前客户端验证。

## 服主还需人工检查

1. 当前 JAR、自己的依赖版本与权限插件下登录/改密/菜单保存重读。
2. 原版客户端标题、换行、图标、颜色/跨样式渐变、tooltip、输入与布局。
3. 在线玩家打开、Shift＋F、当前权限插件补全和真实第三方命令。
4. 测试账号小额买/卖、余额不足、库存不足、限额/冷却；PAPI 实际变量输出。
5. 需要时在测试服验证退款/离线/停服恢复，不以生产数据做破坏性故障注入。
