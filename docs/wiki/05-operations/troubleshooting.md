# 05.4 常见问题与建议操作

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 先保留草稿和文件，再排错。

| 现象/诊断 | 实际含义 | 建议 |
| --- | --- | --- |
| 地址打不开 | 不是服务器电脑、未就绪、端口冲突或认证初始化失败 | 在服务器电脑执行 editor，按实际地址访问；检查启动诊断，不用 0.0.0.0 解决 |
| 编辑器未安装完成说明页 | 前端资源缺失，HTTP 本身可用 | 检查使用完整构建的单 JAR，不把说明页当编辑器成功 |
| 登录错误/429 | 密码错误或失败限制 | 查首次控制台；等待失败窗口，忘记密码停服按流程重置 |
| 401 | 会话到期、退出、改密或重启 | 当前页面草稿留内存，重新登录；不刷新赌草稿恢复 |
| 403 Origin/CSRF | 来源或令牌不匹配 | 用实际 127.0.0.1 同源页面，勿开任意 CORS/拼 URL Token |
| YAML INVALID_YAML | 编码、缩进、重复键、不安全标签/类型 | UTF-8，两空格，引用颜色/百分号；修复后再校验 |
| INVALID_FIELD | 未知字段/类型错误 | 按 JSON Pointer 查字段；数字与字符串分清，不套其他插件格式 |
| MENU_REFERENCE_NOT_FOUND | open_menu 目标未正式存在 | 先保存/导入目标，再导入引用者；不是填显示标题 |
| MENU_REFERENCED | 删除目标仍被引用 | 在引用弹窗跳到引用者修改并保存，不强删 |
| REVISION_CONFLICT | 另一保存先完成 | 保留/导出草稿，重新读取核对，勿盲重试 |
| YAML_SYNC_CONFLICT / pendingImport | 手动 YAML 有未导入修改或双方变化 | 错开编辑，按 reload 导入；不手改 JSON/删基线 |
| unknown 同步 | 缺少可靠基线/同步证据 | 停服备份核查，不通过复制两份文件猜测一致 |
| YAML_SYNC_FAILED | 正式 JSON/注册表已提交，后续导出失败 | 属部分成功，检查文件权限/路径，先读回，别重复交易/保存 |
| PAPI 原标记/非法数字 | 扩展缺失或输出不可用于该条件 | 单独解析验证；ERROR 不用默认 0 或 negate 放行 |
| ECONOMY_UNAVAILABLE | Vault 没找到实际服务 | 检查桥与提供者、启动顺序、meta；PAPI 余额不是替代服务 |
| 余额不足/物品不足/空间不足 | 已知业务拒绝 | 玩家会收到相应短提示，核对金额表达式和商品原型 |
| POST_COMMIT_FAILED | 状态已提交，消息/命令/菜单等副作用失败 | 不声称发货/扣款回滚，不自动重放；用操作 ID 核查 |
| RECOVERY_REQUIRED / RECOVERY_SAVE_FAILED | 补偿或必要持久化结果不明确 | 保留阻断与恢复文件，人工核查实际余额/背包；勿删记录后重买 |
| 服务不可用/网络超时 | 请求可能未完成，也可能服务端已提交 | 保留草稿，读回核查，不盲重试写入 |

报告给开发者时提供版本、诊断码、操作 ID、字段路径和复现步骤；不要贴密码、哈希、Cookie、CSRF、玩家隐私或完整服务器绝对路径。日志中没有堆栈不代表没有错误，故意使用固定诊断保护敏感内容。
