# 04.1 导航与主菜单快捷入口

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 至少两个已保存菜单。

按钮点击方式选“处理点击”，成功动作选“打开其他菜单”，填写目标 **ID** 如 `wiki_01_notice`。`open_menu` 的目标由保存/导入时检查；denyActions 中的导航同样检查。普通字符串或玩家数据内容不是导航引用。

唯一主菜单：在右侧菜单公共属性勾选“快捷打开（设为主菜单）”并保存；其他菜单显示已占用 ID。换主菜单先取消旧菜单并保存，再给新菜单开启。保存前只是草稿勾选，不会抢占入口；删除主菜单后没有自动选择替代者。

游戏潜行＋交换副手（默认 Shift＋F），或 `/dcmenu main` 打开；需要 `dcmenu.shortcut`（默认 true）或已有管理员规则。未潜行、无主菜单、无权限等情况保持普通交换行为。纯 Paper 不监听任意 Ctrl/Alt 组合；玩家改了键位后实际按其“潜行/交换副手”键。

导航使用当前正式版本与既有会话/点击去重；旧界面在版本变化后可能要求重开。不是前端预览请求，网页不会假装执行游戏导航。
