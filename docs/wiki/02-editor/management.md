# 02.1 菜单管理与保存

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 已登录本机编辑器。

## 菜单列表、新建与读取

顶部下拉框选择正式菜单；“新建”建立本页草稿，保存才 POST 新建。“重新读取”获取服务器正式文档及 revision，未保存修改会先提示。列表不包含仅存在于本页的新草稿，也不自动扫描未导入的 YAML。

步骤：选择菜单 → 看右侧 ID/标题 → 修改一个字段并离开 → “校验” → “保存” → 等待结果 → “重新读取”核对。例：标题从“导航”改为“主城导航”，预期重读后仍为新标题。不能只点颜色窗口“应用”就关页面。

## 删除与引用

选择已保存菜单 → “删除菜单” → 阅读确认框。删除检查 revision、YAML 状态及其他菜单引用。遇到 `MENU_REFERENCED` 会出现引用弹窗，列出引用菜单和字段路径，按钮可跳转到引用菜单；跳转前保护未保存草稿。先在引用者修改/删除相关 `open_menu` 并保存，再删除目标。没有强制/级联删除。

自身引用按现有规则不单独阻止删除自身；跨菜单引用来自成功动作和 denyActions。玩家数据中的同名字符串不是菜单引用。

## 浏览器 YAML

“导入 YAML”选择本机 UTF-8、1 MiB 以内的当前格式文件，先预览 ID、标题、警告，再确认进入草稿；不会立刻覆盖正式菜单。已有 ID 保留预览捕获的版本，最终保存仍冲突检查。取消不改草稿；确认替换会清空旧文档撤销历史。

“导出草稿 YAML”先提交合法字段并校验，只下载当前草稿，不改正式文件；有非法数字/未应用窗口先处理。需要服务器已保存版本时先保护草稿再重新读取。导出不保留注释/原排版；不导入 KaMenu 格式，不用文件名猜 ID。
