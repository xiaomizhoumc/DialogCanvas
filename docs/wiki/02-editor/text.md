# 02.3 文字、颜色、渐变与图标

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 能选中组件并找到右侧属性。

## 修改文字与样式

标题、正文、输入标签、按钮文字和 tooltip 使用同一文字编辑器。输入文字后离开编辑框提交；选中文字再点“粗/斜/线/删”，当前样式会高亮。换行用“换行”或正常文本编辑。

颜色：选中“欢迎” → 点“颜色” → 选择 Minecraft 16 色或填 `#55FF55` → “应用”。Hex/RGB/滑块同步，不支持透明度；最近颜色只保存已确认颜色，不保存菜单和认证。没有选区会要求先选文字，不给整段默认改色。

渐变：选中文字 → “渐变” → 添加两种或更多颜色，调整颜色顺序 → 查看临时预览 → “应用”。色标均匀分布，不支持任意位置。再次选中受支持的已保存渐变可继续编辑。

打开窗口不丢选区；改色/拖动只是临时预览，“应用”产生一次菜单修改，“取消”/Esc 不提交。颜色窗口的清除颜色保留其他样式；文字工具栏“清除样式”会清除选区颜色和样式，两者不要混淆。

## 高级文本原文

网页当前**没有格式下拉框或高级源码按钮**。普通、可无损处理的 legacy/MiniMessage 子集可视化编辑；不支持的 MiniMessage 标签、交互组件或复杂 Component 显示“原配置已保留”，不能在网页强制转换。需要修改高级内容时下载/手动编辑 YAML，再按导入流程校验；未知格式不会被悄悄压平成普通文字。

例如 `<bold>粗体</bold>` 可编辑；带高级 hover/click 的复杂结构可能只保留显示。保存时新增丰富样式优先使用 MiniMessage，没改的 TextSpec 保留原格式。HTML/TipTap JSON 不写入游戏文本。

## 图标与展示

按钮图标与 label 分开配置。在“按钮图标注册名”输入 bone、ender_pearl 或 minecraft:diamond_sword，离开输入框或按 Enter 应用，按 Esc 取消。游戏内通过后端确认的 Sprite 映射调用客户端纹理，不把所有 Material 都当成 Sprite。未知图标保留文字并给警告；网页以文字占位，不加载 PNG。图标不继承文字颜色，不支持按钮原生附魔闪光。

正文“物品展示”在“物品注册名”中输入 iron_ingot 或 minecraft:diamond_sword，再按需勾选“添加附魔闪烁光效”，只改变游戏展示；网页不模拟纹理或光效。实际发放物品的真实附魔在动作配置中设置，不能靠正文 glow 实现。

鼠标悬停字段旁 `!` 查看用法与示例；tooltip 则是菜单按钮的游戏悬停文案，二者不同。浏览器渲染使用安全 React 节点，不执行点击命令或 PAPI。
