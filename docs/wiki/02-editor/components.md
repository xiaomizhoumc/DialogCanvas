# 02.2 三栏布局、组件与拖拽

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 已创建或读取菜单。

## 三栏各做什么

左侧提供后端已支持的正文/输入/按钮和节点列表；中间为 Dialog 近似预览；右侧编辑选中项属性。三栏各自上下滚动。点预览里的组件即可选中，空白区域用于菜单公共属性；右键有当前对象适用的复制、删除、粘贴等选项，不表示任意坐标布局。

## 添加、复制、删除、排序

1. 点左侧“文字说明”“物品展示”等组件，或拖入中央对应区域。
2. 点预览/左侧节点选中；右侧修改属性，离开输入框提交。
3. 使用节点旁复制、删除、上下移动；复制后检查按钮 ID、输入 key 等业务标识。
4. 拖动排序在合法区域放开才提交一次修改；Esc/取消不改文档。正文、输入、按钮分区，不允许互相拖成另一种类型。
5. 撤销/重做恢复文档与内部节点身份；一次拖放一个全局撤销点。无业务 ID 的正文也有内部稳定 ID，但不会写入文件。

预期：将两段正文换序，预览和保存重读顺序一致。常见错误：把按钮拖进正文、把“宽度”当作 x 坐标、修改 ID 后不处理引用。

## 菜单类型与槽位

| 类型 | 编辑内容 | 注意 |
| --- | --- | --- |
| 提示 notice | 正文、输入、noticeAction | 不配置 multi_action 的 actions/columns |
| 确认 confirmation | yesButton、noButton | 两个都必填，标签可中文 |
| 多按钮 multi_action | actions 列表、columns、可选 exitAction | 至少一个按钮；退出槽位单独排列 |

类型切换不会静默删掉不兼容字段。若校验提示残留旧槽位，先保留草稿并处理对应配置；不要假设已自动迁移。网页列数控件范围比后端正整数约束更窄，不应依赖超大列数排版。

## 正文、四种输入与按钮

正文文字可设宽度；物品正文可带旁边说明 `description`，悬停 `lore` 是另一件事。输入选择：勾选确认用 bool；备注用 text；选数量用 number_range；固定选项用 single_option。单选项“初始”最多一个，回传的是选项 ID。

输入 key 例 `amount`，按钮 ID 例 `buy`，菜单 ID 例 `wiki_shop`，三个不是同一个标识。改 key 会影响条件/动作表达式；校验错误需修正引用。数字可暂时留空/输入中间值，此时显示提示并保留旧合法模型，不能保存/导出非法状态。

## 四种输入各做一次

从左侧点击对应组件，选中后在右侧填写；每个输入都先设置唯一“输入标识”和“显示文字”。

| 左侧组件 | 右侧填写示例 | 预期与常见错误 |
| --- | --- | --- |
| 勾选框 | 输入标识 confirm，显示文字“我已确认”，不选“初始勾选” | 预览可勾选；仅有勾选框不自动限制购买，必须添加读取 confirm 的条件 |
| 文字输入 | 标识 note，显示文字“备注”，初始文字留空，最大长度 32 | 玩家可填备注；默认不能拿它当数字计算。数字数量需勾选“作为数值参与条件和动作计算”，再设最小值/最大值 |
| 数量滑块 | 标识 amount，显示文字“数量”，开始 1、结束 16、步进 1、初始数值 1 | 预览滑块从 1 到 16；结束小于开始或初始值越界会拒绝。数量传给动作时使用 $(amount) |
| 单选列表 | 标识 delivery，显示文字“配送”，在“选项”点“添加”；两项 ID 分别 normal/express，选项文字“普通”/“加急”，勾普通为“初始项” | 预览能切换；返回的是 ID，不是中文。删除后不留空数组，选项 ID 不能重复，初始项最多一个 |

完成后“校验”→“保存”→“重新读取”，核对初始值仍在。预览中试选/输入只影响演示，不会修改配置初始值、提交备注或执行业务。[四输入完整 YAML](../../../examples/wiki/menus/wiki_04_inputs.yml) 可直接导入对照。
