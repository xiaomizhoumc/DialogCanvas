# 02.5 预览、撤销、草稿与异常

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

> 适用：DialogCanvas 1.0.0，Paper 26.1～26.3 系列（构建范围见最终验收）；核对日期：2026-10-16。

**前置知识：** 了解编辑与保存不是同一步。

## 四个状态

| 状态 | 发生什么 | 能否认为游戏已更新 |
| --- | --- | --- |
| 临时预览 | 正在输入，或颜色/渐变窗口改值；合法值叠到预览 | 不能 |
| 已应用编辑 | 字段失焦/Enter，窗口“应用”，拖放完成；进入文档撤销历史 | 不能 |
| 正式保存 | JSON 与内存注册表均提交；随后同步 YAML | 新打开菜单使用新版本；旧界面可能需重开 |
| 游戏内确认 | 玩家实际打开、检查显示/回调 | 这是客户端验收，网页不能代替 |

临时层不修改保存基线。非法数字保持可输入，显示错误并保留旧合法预览；Esc 取消本字段。切换选中项、读取另一菜单、撤销会清理临时层；先完成当前字段再切换，别依靠未应用窗口自动保存。

## 撤销边界

连续文字/属性输入到失焦/Enter 合成一次提交；一次颜色/渐变应用、一次拖放、复制、删除各为独立修改。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；在文字输入区域先遵循 TipTap/浏览器局部撤销，不会同一次快捷键双重撤销。保存本身不新增撤销点；保存后撤销会重新变为未保存。读取/确认导入另一文档清空旧历史。

## 保存与异常

- “保存全部完成”：正式数据和 YAML 同步完成。
- “正式数据已保存，但 YAML 同步失败”：部分成功，不要重复提交；读回核查，处理文件权限/同步状态。
- 版本冲突：其他标签页已保存，草稿保留。先导出/自行保留草稿，再重新读取核对，不能盲覆盖。
- YAML 待导入：错开网页与手改；先按控制台 reload 导入，再重新读取，不删除基线。
- 401 会话失效：当前页面内存草稿/历史保留，重新登录不自动覆盖；重启、改密都会令旧会话失效。
- 网络中断/30 秒超时：写入结果可能不确定，不自动重试；读取核查后决定。服务端可能已提交，客户端超时不是取消证明。

切换菜单、退出、关闭页面前有未保存提示，但**刷新/关闭后不保证恢复草稿**。菜单/认证不存 localStorage/sessionStorage；最近颜色仅保存颜色。下载草稿是可用的主动备份方式，不是服务器历史版本。
