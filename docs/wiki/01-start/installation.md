# 01.2 安装、目录与登录

[返回 Wiki 首页](../README.md) 

**前置知识：** 上一章；能操作服务器控制台和文件夹。

## 环境

运行支持 **Paper 26.1～26.3 系列、Java 25**；同一份 JAR 已测 26.1.1 Build 29（Alpha）、26.1.2 Build 74、26.2 Build 134、26.3 Build 194。官方没有独立 `26.1` 版本号的下载，不承诺所有历史构建/预发布版或其他分支。元数据 `api-version: '26.1'` 是最低 API；编译仍固定 Build 74。运行用匹配服务端的原版兼容客户端，客户端效果仍须人工确认。

纯菜单无可选依赖。经济需要 Vault 兼容桥 **以及** 真正的经济提供者；PAPI 变量需要 PlaceholderAPI 及提供该变量的扩展。项目编译 PAPI 版本为 2.12.3；历史隔离环境验证过 VaultUnlocked 2.20.2 + EssentialsX 2.22.0 的服务发现，不代表任意版本都验证过。

## 首次安装

当前插件还会生成 `plugins/DialogCanvas/examples/menus/` 下十份完整中文注释教学 YAML，附 `examples/使用说明.md`；后续启动只补齐缺失文件，已有内容保留。它们是按需导入的教学原件，不会因文件生成自动加载菜单或执行商店交易。

1. 正常 `stop`，等世界保存和 Java 进程退出。备份服务器。
2. 将插件 放入服务器 `plugins/`，只保留一个本插件 JAR。**不要在运行中覆盖 JAR 后再 stop**，旧类加载器收尾会受损。
3. 启动，等待服务器及 DCMenu 后台初始化就绪。首次没有密码哈希时，控制台显示一次“DCMenu 首次初始化密码（仅此一次显示，请妥善保存）”。立即妥善保存；插件正常日志不保存明文，启动器录屏/重定向可能例外。
4. 控制台输入 `dcmenu editor`，复制实际输出地址，在**服务器电脑**浏览器打开。默认 `http://127.0.0.1:8080/`，配置端口改变后以命令为准。
5. 顶部“管理员密码”填首次密码，点击“登录”。不要把密码拼在 URL 后。
6. 退出使用“退出”；改密使用“修改密码”，输入当前密码、新密码和确认值。改密撤销所有会话；普通退出只撤销当前会话。固定 24 小时到期，重启后全部失效。

忘记密码：正常停服，备份配置，把 `password-hash` 清空，再启动获取新的首次密码。不要把明文写入该键，不在运行中改配置。

## 默认目录

以下以插件数据文件夹 `plugins/DialogCanvas/` 为根；`data` 随 `data-directory` 改变，`menus`/`playerdata` 不随它移动。

| 路径 | 内容与操作方式 |
| --- | --- |
| `config.yml` | 设置、BCrypt 哈希；设置变更需正常重启 |
| `data/menus/<id>.json` | 正式菜单，启动/API/注册表依据；勿运行中手改 |
| `menus/<id>.yml` | 服主手动编辑入口，改后 `dcmenu reload <id>` |
| `data/menu-sync/<id>.json` | 同步摘要/导出意图，由插件维护 |
| `playerdata/<uuid>.yml` | 限购和冷却，不能当无用缓存删除 |
| `data/player-data/`、`data/transactions/`、`data/recovery/` | 业务数据、交易和补偿恢复 |
| `data/retention-backups/` | 安全归档/恢复的备份，不自动清理 |
| `logs/audit.log` | 插件目录内的管理审计，不是服务器根 logs |

目录可能在相关服务初始化或首次写入时才出现。端口失败不会给出虚假可用地址；正式菜单仓库与游戏动作初始化独立于 HTTP 监听，已就绪游戏功能可继续，具体看控制台状态。认证/仓库初始化失败则相关入口不可用，不等同于只有端口冲突。
