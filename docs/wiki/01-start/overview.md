# 01.1 插件用途与能力范围

[返回 Wiki 首页](../README.md) · [项目入口](../../../README.md)

## 它能做什么

DialogCanvas（简称 DCMenu）是 Paper 服务端插件。服主在服务器电脑的浏览器编辑原生 Dialog 菜单，再在游戏中打开已保存菜单。交付为一个 JAR；浏览器运行不依赖 Node.js、CDN、独立网站、数据库或账号权限系统。

当前有提示、确认、多按钮三类菜单；正文可用文字和物品展示，输入有勾选、文字、数字滑块、单选。按钮可以导航、检查条件、执行命令、读写玩家业务数据、限购/冷却，以及通过 Vault 经济服务买卖物品。

## 先知道的限制

- 网页是近似预览，不执行交易，不是游戏实时预览；布局使用原生列表和列数，不能任意放置坐标。
- 编辑器只绑定服务器电脑的 `127.0.0.1`，另一台电脑不能直接用这个地址访问。没有公网部署模式。
- 单管理员密码，所有已登录会话管理同一批菜单。多标签页靠 revision 防覆盖，不等于协同编辑。
- 条件/动作参考 KaMenu 的思路；配置不是 KaMenu 格式，不能直接导入其他插件菜单。
- 不提供模板、历史版本浏览、diff、WebSocket、全服维度限购、资源包图标编辑或自动重试交易。
- 纯 Paper 不能仅凭任意名称生成其他插件私有或客户端模组物品。

## 三种“物品”别混淆

| 位置 | 用途 | 会进入背包吗 |
| --- | --- | --- |
| 正文的物品展示 | 看物品、悬停说明、旁边文字，可覆盖展示闪光 | 不会 |
| 按钮的独立图标 | 图标加按钮文字，来自已确认 Sprite 映射 | 不会 |
| 成功动作中的给物品 | 按数量发货，可含真实附魔与属性 | 会 |

先做不执行业务的提示菜单，再学习导航，最后在测试服配置商店。
